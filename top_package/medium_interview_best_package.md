## 📋 Prep Checklist for Medium Interviews

### DSA Topics to Cover
- [ ] Arrays, strings, sliding window, two pointers
- [ ] HashMap, HashSet patterns
- [ ] Binary search (on sorted arrays + answer space)
- [ ] Trees — BFS, DFS, level order
- [ ] Graphs — BFS, DFS, topological sort, Dijkstra
- [ ] Dynamic programming — 1D, 2D, knapsack, LCS
- [ ] Heap / priority queue — top-K, merge K lists
- [ ] Stack + monotonic stack
- [ ] Linked list — reversal, cycle detection, merge

### System Design Topics
- [ ] URL shortener / TinyURL
- [ ] Rate limiter
- [ ] Notification system (push + email) — directly matches your FCM + SES work
- [ ] Real-time stock ticker / market data feed — your strongest card
- [ ] Payment gateway / webhook pipeline — your TradingView pipeline is a direct case study
- [ ] Event-driven architecture with queues — your SQS + ActiveMQ experience
- [ ] AWS serverless design — your Lambda + API Gateway architecture
- [ ] Database migration design — your MySQL→MongoDB + DynamoDB→MySQL work

### Domain Knowledge (for fintech / financial data roles)
- [ ] How stock exchanges work (order book, matching engine basics)
- [ ] What OHLCV data is and how it's processed
- [ ] How payment gateways and webhooks work
- [ ] What Kafka / message queues solve at scale
- [ ] Basic index construction (for MSCI / LSEG roles)
